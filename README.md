# HoldMyRAM

A small Windows tray app that frees RAM on demand. You choose which apps,
startup items, scheduled tasks and services it may close, see a risk rating and
a short explanation for each, and toggle the set with a global hotkey. Toggling
off restores what was closed.

Status: early (v0.1.0). Unsigned and not an installer. Free software under the
GNU General Public License, version 3 (see `LICENSE`), with no warranty.

## Requirements

- Windows 10 or 11, x64
- Microsoft Edge WebView2 runtime. Built into Windows 11 and most updated
  Windows 10 installs; otherwise get it from
  <https://developer.microsoft.com/microsoft-edge/webview2/>

## Run a release build

1. Unzip `HoldMyRAM-<version>-win-x64.zip` anywhere.
2. Keep `holdmyram.exe` and `holdmyram-helper.exe` in the same folder (the helper
   refuses to run without `holdmyram.exe` next to it).
3. Run `holdmyram.exe`. Find the tray icon (possibly under the `^` arrow).
4. Default hotkey: `Ctrl+Alt+R`. The foreground app is never closed by it.

### Prompts you will see

- **UAC, "Unknown publisher":** only when toggling services or scheduled tasks.
  The app runs as your normal user; a short-lived helper asks for elevation.
  Declining it is fine; other items still work.
- **SmartScreen:** the exe is unsigned. Click "More info", then "Run anyway".

## Data locations

- `%APPDATA%\HoldMyRAM`: settings, profiles, risk overrides
- `%LOCALAPPDATA%\HoldMyRAM`: restore journal

## Uninstall

Quit from the tray icon, delete the folder, and optionally delete the two data
folders above and the `HoldMyRAM` value under
`HKCU\Software\Microsoft\Windows\CurrentVersion\Run` if you ticked
Settings > Start HoldMyRAM when I sign in (off by default).

## Updates

HoldMyRAM checks the project's GitHub Releases for newer versions and offers to
install them. It verifies the download against `SHA256SUMS.txt` from the same
release. To update by hand, quit from the tray and extract the new zip over the
folder (keep both exes together). The checksum check protects against a
corrupted download, not against a compromised account or release, because the
checksums come from the same place as the file.

## Build from source

Requires Rust (<https://rustup.rs>) and the Windows MSVC build tools.

```powershell
powershell -ExecutionPolicy Bypass -File scripts\package.ps1
```

This builds in release mode and writes `dist\HoldMyRAM-<version>-win-x64\` and a
matching `.zip` and `.sha256`. `scripts\make-icons.ps1` regenerates the icons.

## Limits

Unsigned, no installer, no auto-update, Windows x64 only. Closing apps can lose
their unsaved work.
